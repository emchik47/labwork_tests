# Общее описание
- Проект создан для нахождения характеристик геометрических фигур

# Стурктура проекта
- Проект содержит 4 файла: `circle.py`, `square.py`, `rectangle.py`, `triangle.py`

## circle.py
- Файл содержит 2 функции: `area` и `perimeter`
### area
- Принимает радиус r круга и возвращает его площадь по формуле **S = πR<sup>2</sup>**
- Пример:
> Вызов функции: area(5)  
Возвращаемое значение: 78.53981633974483
### perimeter
- Принимает радиус r круга и возвращает его периметр по формуле **P = 2πR**
- Пример:
> Вызов функции: perimeter(3)  
Возвращаемое значение: 18.84955592153876

## square.py
- Файл содержит 2 функции: `area` и `perimeter`
### area
- Принимает длину стороны квадрата a и возвращает его площадь по формуле **S = a<sup>2</sup>**
- Пример:
> Вызов функции: area(4)  
Возвращаемое значение: 16
### perimeter
- Принимает длину стороны квадрата a и возвращает его периметр по формуле **P = 4a**
- Пример:
> Вызов функции: perimeter(6)  
Возвращаемое значение: 24

## rectangle.py
- Файл содержит 2 функции: `area` и `perimeter`
### area
- Принимает длины сторон прямоугольника a и b и возвращает его площадь по формуле **S = a * b**
- Пример:
> Вызов функции: area(4, 5)  
Возвращаемое значение: 20
### perimeter
- Принимает длины сторон прямоугольника a и b и возвращает его периметр по формуле **P = 2 * (a + b)**
- Пример:
> Вызов функции: perimeter(6, 4)  
Возвращаемое значение: 20

## triangle.py
- Файл содержит 2 функции: `area` и `perimeter`
### area
- Принимает длины стороны и высоты треугольника a и h и возвращает его площадь по формуле **S = a * h / 2**
- Пример:
> Вызов функции: area(4, 5)
Возвращаемое значение: 10
### perimeter
- Принимает длины сторон треугольника a, b и c и возвращает его периметр по формуле **P = a + b + c**
- Пример:
> Вызов функции: perimeter(6, 4, 5)  
Возвращаемое значение: 15

# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle S = a * h / 2

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle P = a + b + c
