Отчет по тестированию

1. Цели и задачи тестирования

Цели:

Проверить корректность работы математических функций для вычисления площади и периметра геометрических фигур (прямоугольник, круг, треугольник, квадрат)
Убедиться в правильной обработке некорректных входных данных (отрицательные числа, нулевые значения)
Обеспечить соответствие функциональности заявленным требованиям

Задачи:

Провести модульное тестирование каждой функции
Проверить обработку граничных случаев
Проверить обработку ошибок при невалидных входных данных
Убедиться в точности математических вычислений

2. Описание тестируемого продукта

Продукт представляет собой набор математических функций на Python для вычисления:

Площади и периметра прямоугольника (файл rectangle.py)
Площади и периметра круга (файл circle.py)
Площади и периметра треугольника (файл triangle.py)
Площади и периметра квадрата (файл square.py)

Особенности:

Все функции включают валидацию входных данных
При некорректных данных выводится сообщение об ошибке и возвращается -1
Для треугольника дополнительно проверяется корректность длин сторон

3. Область тестирования

Объекты тестирования:

Функция area() для каждой фигуры
Функция perimeter() для каждой фигуры

Классы тестов для каждой фигуры:

RectangleTestCase
CircleTestCase
TriangleTestCase
SquareTestCase
Тестируемые аспекты:

Корректность математических вычислений
Обработка нулевых значений
Обработка отрицательных значений
Корректность проверки треугольника на существование

4. Стратегия тестирования

Методы тестирования:

Модульное тестирование (Unit Testing) - тестирование отдельных функций
Функциональное тестирование - проверка соответствия функциональным требованиям
Тестирование граничных значений - проверка поведения на граничных условиях
Негативное тестирование - проверка обработки некорректных данных

Техники тестирования:

Тестирование "черного ящика" (без знания внутренней реализации)
Использование фреймворка unittest для организации тестов

5. Критерии приемки

Критерии успешного завершения тестирования:

Все тестовые случаи выполняются успешно
Функции возвращают правильные значения для корректных входных данных
Функции корректно обрабатывают некорректные входные данные (возвращают -1)
Для треугольника правильно определяется невозможность треугольника по неравенству треугольника
Покрытие тестами основных сценариев использования
